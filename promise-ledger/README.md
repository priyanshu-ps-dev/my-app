# Promise Ledger

A lightweight B2B payment-promise and collections follow-up dashboard.

## What it does
- Track customer payment commitments
- See overdue, due-today, upcoming and paid items
- Add follow-up notes and conversation history
- Reschedule promise dates
- Draft a WhatsApp follow-up message
- Mark payments as received
- Search records
- Export/import CSV
- Persist demo data in the browser with localStorage

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

Example:
```bash
npx serve .
```

## Deployment
The app is static and can be deployed on GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

## Project goal
Promise Ledger is designed for small B2B teams that currently track payment commitments in WhatsApp, spreadsheets, or memory and need a clear daily follow-up queue.
